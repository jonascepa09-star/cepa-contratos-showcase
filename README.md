# CEPA — Sistema de Contratos Digitais

Sistema web **funcional e pronto para produção**, desenvolvido por Jonas para a administração de contratos educacionais. O código-fonte original permanece privado.

## Demonstração interativa

**[Abrir demonstração do sistema →](https://sistema-cepa-contratos.vercel.app/demo)**

A rota `/demo` apresenta o funcionamento do produto com **dados fictícios e ações simuladas**, sem necessidade de acessar contratos ou contas reais. A demonstração inclui:

- **Painel de contratos:** indicadores de contratos assinados, aguardando assinatura e encerrados
- **Gestão:** pesquisa por aluno, CPF, curso, turma e identificação; filtros por status e curso
- **Operações:** criação de contrato, visualização de links e ações de gerenciamento simuladas
- **Modelos:** listagem por curso, versões e opção de criar nova versão
- **Assinatura:** leitura do contrato, preenchimento de dados, consentimentos e assinatura desenhada na tela
- **Navegação:** seções de contratos, modelos e auditoria

### Imagens da demonstração

As capturas da interface serão adicionadas à apresentação pública. Enquanto isso, você pode **[explorar a demo online](https://sistema-cepa-contratos.vercel.app/demo)**.

## Tecnologias

Next.js 16 · TypeScript · Tailwind CSS · Supabase (PostgreSQL, Auth e Storage) · Playwright · Vercel.

## Ambiente real

[Aplicação principal](https://sistema-cepa-contratos.vercel.app/)

A demonstração é separada do uso real e não deve receber informações pessoais verdadeiras. Este repositório **não publica código-fonte**, contratos reais, dados de estudantes, credenciais ou chaves de API.
