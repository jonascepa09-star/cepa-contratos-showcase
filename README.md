# CEPA — Sistema de Contratos Digitais

Sistema web **totalmente funcional e pronto para produção**, desenvolvido por Jonas para administrar contratos educacionais. O código-fonte permanece privado.

## Funcionalidades
- Painel administrativo e autenticação
- Emissão e gerenciamento de contratos
- Assinatura digital pelo celular
- Geração de contratos em PDF
- Versionamento e verificação por código/QR Code
- Armazenamento e gestão de documentos

**Tecnologias:** Next.js 16, TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth e Storage), Playwright e Vercel.

## Demonstração
Está em desenvolvimento uma rota **`/demo`**, destinada a demonstrar as funcionalidades com informações fictícias, sem acesso a contratos reais. O link da demonstração será adicionado quando estiver pronto.

**Aplicação:** https://sistema-cepa-contratos.vercel.app/

> O ambiente real não é um sandbox público. Não use credenciais administrativas ou dados pessoais para demonstrações.
